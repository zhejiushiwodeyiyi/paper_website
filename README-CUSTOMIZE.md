# Customizing This Paper Site

This workspace is now a reusable paper-site template based on the reference repository.

## Main content file

Edit `src/data/site.ts` to replace:

- site title and description
- author / institution text in the top navigation
- hero summary
- summary cards
- backbone / methods / robustness / significance copy
- glossary and resource labels

## Static assets

Replace files in `public/` to match your paper:

- `public/pdfs/main.pdf`
- `public/pdfs/supplement.pdf`
- `public/figs/*`
- `public/modules/*`
- `public/acf-cv/*`

## Current limitation

The current homepage has been rebuilt as a clean template version first. It preserves the overall academic one-page site structure and the main figure sections, but it is not yet a pixel-perfect recreation of the original interactive phase explorer.

To finish the paper-specific version, the next step is to replace the current COVID manuscript data and figures with your own paper materials.
